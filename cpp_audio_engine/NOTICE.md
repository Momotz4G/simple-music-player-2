# Notice

The custom C++ audio engine and ALAC decoder used in this project are hosted in a **private repository**. 

This folder intentionally does not contain the source code. If you want to build this project to achieve Android bit-perfect playback for devices older than Android 14, you will need the proprietary engine files.

If you are interested in accessing the engine source code for development or educational purposes, you may contact the author to ask for permission.
